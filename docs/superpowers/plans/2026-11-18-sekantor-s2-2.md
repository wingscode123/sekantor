# SeKantor S2.2 (project rooms) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Each project gets its own room (walls, a door, a name sign) themed by what the project is;
your workspace is a lobby at the front centre; signs explain each place; agents walk through doors and
a corridor; the header shows the SeKantor brand; the office fits and is crisp at 100% browser zoom.

**Owner decisions (2026-11-18):** your workspace at the front centre; theme list as proposed; fit at
100% zoom.

## Global Constraints

- Detection is local only: read files in the session's working folder; no network, no AI call.
- Original, procedural art (palette indexes, `TILE` = 32), S2 performance rules (static layer cache,
  sprite cache, ≤ 12 fps, nothing while hidden, no timers when idle).
- Never touch port 7878, Task Scheduler or the real home in tests. No push. Commits end with the
  worker's Co-Authored-By trailer.

## Shared contract

Project kinds: `"web" | "backend" | "data" | "mobile" | "game" | "infra" | "docs" | "other"`.

Session JSON (hub, Task 1) gains `project: { name: string, kind: Kind, signals: string[] } | null`.

Office model (web, Task 2) gains:
```ts
export interface Room { project: string; kind: Kind; x: number; y: number; w: number; h: number;
  door: Pt; sign: Pt; desks: Pt[]; rack: Pt; pantry: Pt }
export interface Lobby { x: number; y: number; w: number; h: number; yourDesk: Pt; door: Pt; corridorY: number }
// Office keeps width/height/avatars; adds rooms: Room[]; lobby: Lobby; places: { kind: "your_desk"|"rack"|"pantry"|"door"; at: Pt; room?: string }[]
export function route(office: Office, from: Pt, to: Pt): Pt[]; // waypoints through room doors and the corridor
```
Layout: rooms in a grid behind (top/sides of) a corridor; the lobby (your workspace + exit door) at the
front centre (bottom middle). An avatar's rack/pantry are its own room's; needs you / report → your
desk in the lobby; ended → the lobby exit door.

---

### Task 1: Project detection (hub, Python)
`src/sekantor/projects.py`: `detect(cwd) -> {"name","kind","signals"}` with rules: package.json deps
(react/vue/svelte/next/vite → web; react-native/expo → mobile; express/fastify/nest → backend; phaser/three(+game words) → game),
pyproject/requirements (fastapi/django/flask → backend; pandas/numpy/torch/sklearn/jupyter → data; pygame → game),
Cargo.toml (bevy → game; axum/actix → backend), pubspec.yaml/AndroidManifest/xcodeproj → mobile,
Dockerfile/terraform/*.tf/k8s/helm/ansible → infra, mostly .md and no code → docs, else other; name =
git root folder name (fallback cwd basename); OpenBot sessions → name "OpenBot agents", kind other.
Cached per folder (re-detect at most every 10 min), cheap (stat + small reads, capped bytes).
Config override: `[projects] "<name>" = "<kind>"` in config.toml. `session_json` adds `project`.
Tests with temp folders per kind + override + caching. Commit `feat(hub): detect what a project is`.

### Task 2: Rooms, routing, labels, header, scale (web model + page)
Model/layout/route per the contract (tests: rooms don't overlap, lobby front centre, every desk inside
its room, route never crosses a wall, 25 sessions / 6 projects fit); motion follows `route` waypoints;
place signs ("Your desk: permissions, questions, reports", "Server rack: running commands",
"Pantry: idle", "Exit: session ended") as DOM labels with a tooltip/longer description, and the room name
sign per room; fix plates (they sit several tiles above the desk since TILE became 32) — plate anchored
to the avatar's desk; header uses the SeKantor lockup (`web/public/lockup.svg`) instead of the Ronda
mark/text; scale: fit the office to the viewport width at 100% zoom with integer device-pixel scaling
(use devicePixelRatio; never blurry), vertical scroll if taller. Commit `feat(web): project rooms and lobby`.

### Task 3: Room art (web sprites)
Walls, door frames and a name-sign plate for rooms; the lobby with your desk, a reception look and the
exit door; corridor floor; per-kind decor sets drawn in the static layer: web = design studio
(sketch boards, wide screens), backend = machine room (extra racks, cables), data = lab (chart
whiteboard, flasks), mobile = gadget room (phone shelves), game = arcade (cabinets, colourful rug),
infra = big server room, docs = library (full bookshelves), other = standard office. Theme API:
`theme.room(kind, ctx, room)` drawn into the static layer. Commit `feat(web): themed project rooms`.
