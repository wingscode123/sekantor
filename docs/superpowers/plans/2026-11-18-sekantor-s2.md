# SeKantor S2 (the office) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the inbox web UI with a 2D pixel-art office: one desk and avatar per agent, desks
grouped by project, avatars animated by status and activity, walking to your desk when they need you,
a card with "Open in <app>", and a mini view for a small always-on-top window.

**Architecture:** Everything is in `web/` (React + TypeScript, served by the hub and shown in the
Tauri window). A pure model (`office/model.ts`) turns the live `Session[]` from `/v1/stream` into an
office layout; a Canvas 2D renderer (`office/render.ts`) draws it at 12 fps from procedurally drawn,
original pixel sprites (`office/sprites.ts`); React components overlay name plates and the avatar card.
No hub changes are needed: sessions already carry status, activity, workspace, host and labels.

**Tech Stack:** React 18, TypeScript 5, Vite 5, Canvas 2D (no game engine), Vitest for unit tests.

**Spec:** `docs/superpowers/specs/2026-11-16-sekantor-design.md` sections 6.1-6.4 and 9 (S2).

## Global Constraints

- Art: original, procedurally drawn pixel sprites (16x16 tiles, 16x24 characters, integer scaling,
  `imageSmoothingEnabled = false`). Must not resemble any existing game. The CC0 kit choice is still
  open (owner); sprites live behind a `Theme` object so a kit can replace them later (S3).
- Idle cost: at most 12 fps; no drawing while `document.hidden`; no timers when no session exists.
- Replies stay in the source app: the card has "Open in <app>" (existing `POST /v1/sessions/{id}/open`)
  and snooze; no answer controls.
- Accessibility: every agent is also in an offscreen list (name, app, project, status) for screen
  readers; the canvas has `role="img"` and an `aria-label` summary; the card is keyboard reachable.
- Local only: no new network origins, no web fonts from the network (fonts are bundled already).
- Tests never touch the real hub or port 7878. `cd web && npm run build` and `npm test` pass before
  each commit. Python suite unaffected. Commit messages end with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. No push without the owner's approval
  (CircleCI credits are exhausted).

## Review Focus

1. 20+ agents (the owner runs 9 OpenBot agents plus Claude sessions): layout stays inside the canvas,
   clusters wrap, nothing overlaps. (Task 1 test with 25 sessions in 6 projects.)
2. A session flips status rapidly (running → waiting → running within a second): the avatar does not
   teleport or get stuck mid-walk; it re-targets. (Task 2 test.)
3. Sessions without workspace/host/agent name (OpenBot, tmux): they still get a desk, a name plate and
   a stable look. (Task 1 test.)
4. Ended sessions: the avatar leaves through the door and the desk is freed after the walk, not
   instantly. (Tasks 1-2 tests.)
5. Hub disconnect/unauthorized: the office shows a clear banner and keeps the last frame, no blank
   canvas. (Task 3 test.)

### Task 1: Office model (pure TypeScript)

**Files:** create `web/src/office/model.ts`, `web/src/office/model.test.ts`; modify `web/package.json`
(add `vitest` devDependency, script `"test": "vitest run"`), `web/vite.config.ts` if needed.

**Interfaces (produces):**
```ts
export type Place = "desk" | "your_desk" | "rack" | "pantry" | "door";
export type Pose = "type" | "read" | "run" | "web" | "work" | "ask" | "smoke" | "coffee" | "leave";
export interface Look { body: number; hair: number; shirt: number; accessory: number } // palette indexes
export interface Avatar { key: string; sessionId: string; identity: string; seat: number; look: Look;
  place: Place; pose: Pose; deskTile: { x: number; y: number }; name: string; app: string; project: string }
export interface Cluster { project: string; origin: { x: number; y: number }; desks: { x: number; y: number }[] }
export interface Office { width: number; height: number; clusters: Cluster[]; yourDesk: { x: number; y: number };
  rack: { x: number; y: number }; pantry: { x: number; y: number }; door: { x: number; y: number }; avatars: Avatar[] }
export function poseFor(s: Session): { place: Place; pose: Pose };
export function identityOf(s: Session): string;      // "<app>|<project>" for Claude Code, "<app>|<agent name>" for OpenBot
export function lookFor(identity: string, seat: number): Look; // deterministic hash
export function layoutOffice(sessions: Session[]): Office; // tile units
```
Rules: project = git repo folder name from `workspace.cwd` (last path segment; "unknown" if none);
clusters sorted by project name, 2 rows x 4 desks each, wrapping into new cluster rows; seat = lowest
free index among live sessions of the same identity (sorted by `started_at`); `poseFor`:
waiting_* → your_desk/ask; error → desk/smoke; done → pantry/coffee; ended → door/leave; running →
desk with pose by `activity.kind`: read→desk/read, edit→desk/type, run→rack/run, web→desk/web,
other or none→desk/work.

- [ ] Failing tests: pose table (every status and activity kind); identity for Claude Code vs OpenBot;
  two concurrent sessions same project → seats 0 and 1, different looks; look stable across calls;
  25 sessions in 6 projects → no overlapping desk tiles, all inside width/height (Review Focus 1);
  session with no workspace/host/agent → desk + name (Focus 3).
- [ ] Implement; `npm test` and `npm run build` pass; commit `feat(web): office model`.

### Task 2: Sprites and renderer (Canvas 2D)

**Files:** create `web/src/office/sprites.ts`, `web/src/office/render.ts`, `web/src/office/motion.ts`,
tests `web/src/office/motion.test.ts`, `web/src/office/sprites.test.ts`.

**Interfaces:**
- Consumes Task 1 types (`Office`, `Avatar`, `Pose`, `Look`).
- `sprites.ts`: `export interface Theme { palette: string[]; tile(kind: TileKind, ctx, x, y): void;
  character(look: Look, pose: Pose, frame: number, ctx, x, y): void; furniture(kind, ctx, x, y): void }`,
  `export const defaultTheme: Theme` — floor, wall, desk+monitor, chair, server rack (blinking lights
  frame), coffee machine, plant, door, your desk; characters with 2-4 frames per pose (typing hands,
  page flip, walking legs, "!" balloon for ask, smoke puff for error, cup for coffee). Drawn with
  `fillRect` per pixel from small string grids, cached to offscreen canvases per (look, pose, frame).
- `motion.ts`: `export function step(positions: Map<string, Pt>, targets: Map<string, Pt>, dtMs: number,
  speed = 4 /* tiles/s */): Map<string, Pt>` moving along x then y on the tile grid; a new target
  re-targets from the current position (Review Focus 2); `leaving(key)` true until the door is reached
  (Focus 4).
- `render.ts`: `export function startRenderer(canvas, getOffice: () => Office, theme = defaultTheme):
  () => void` — 12 fps loop via `setTimeout`/`requestAnimationFrame`, integer scale to fit the canvas,
  stops while `document.hidden`, returns a stop function.
- [ ] Failing tests: motion moves at speed, re-targets mid-walk without jumping, arrives exactly; a
  leaving avatar is kept until it reaches the door; sprite grids are all 16x24 / 16x16 and use only
  palette indexes; renderer does not schedule frames while hidden (fake timers + mocked document).
- [ ] Implement; tests + build pass; commit `feat(web): pixel sprites and office renderer`.
